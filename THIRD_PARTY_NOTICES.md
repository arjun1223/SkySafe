# UI component credits

SkySafe adapts two Uiverse components for its monochrome instrument interface:

- **martinval9 — white-lionfish-18**: rectangular toggle used for light/dark theme and automatic load sweep. [Uiverse original](https://uiverse.io/martinval9/white-lionfish-18), [source](https://github.com/uiverse-io/galaxy/blob/main/Toggle-switches/martinval9_white-lionfish-18.html).
- **cssbuttons-io — friendly-dragon-76**: hover/pressed movement adapted for the primary baseline button. The original pill shape and expanding halo are removed. [Uiverse original](https://uiverse.io/cssbuttons-io/friendly-dragon-76), [source](https://github.com/uiverse-io/galaxy/blob/main/Buttons/cssbuttons-io_friendly-dragon-76.html).

Changes include theme variables, keyboard focus, reduced motion support, dimensions and restrained hover effects. The original files and the Uiverse repository license are retained in `docs/uiverse/`.
